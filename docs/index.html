Nano 33 BLE Sense의 내장 센서를 브라우저 대시보드 또는 스마트폰 phyphox 앱에 실시간 표시·기록·내보내기. 학생이 상황에 따라 USB Serial / BLE WebUI / phyphox(모바일)를 골라 쓰는 프로젝트.

01

프로젝트 요약

"센서값이 어떻게 화면까지 오는가"를 보드 → 통신 → 브라우저로 직접 따라가 보는 프로젝트입니다.

Nano 33 BLE Sense가 내장 센서(가속도·온습도·기압·광/제스처 등)를 읽어 USB Serial 또는 BLE로 전송합니다. 브라우저 단일 HTML 대시보드가 이를 수신·파싱해 Chart.js로 실시간 그래프를 그리고, 수집 데이터를 CSV/XLSX로 내보냅니다. 무선이 필요 없으면 USB로 확실하게, 무선 실습이 필요하면 BLE로 — 한 대시보드에서 모드만 바꾸면 됩니다.

저장소 구조

Arduino_Nano33_BLE_SensorLab/
├─ firmware/                       # 보드 펌웨어 (.ino)
│  ├─ nano33ble_dashboard_rev1.ino # Rev1 (HTS221·LSM9DS1)
│  └─ nano33ble_dashboard_rev2.ino # Rev2 (HS300x·BMI270)
├─ docs/                           # GitHub Pages (/docs)
│  ├─ index.html                   # 이 개요 페이지
│  ├─ manual.html                  # 운용 매뉴얼
│  ├─ dashboard.html               # 배포용 — 라이브러리 내장·오프라인
│  └─ dashboard_cdn_dev.html       # 개발용 — CDN 로드·인터넷 필요
├─ README.md
└─ .gitignore
접속 — Web Bluetooth는 file://에서 동작하지 않으므로 GitHub Pages(https)로 호스팅해야 BLE가 연결됩니다. 개요·대시보드가 모두 docs/에 있으므로 Pages 소스는 /docs로 둡니다.
두 대시보드 파일 — dashboard.html은 Chart.js·SheetJS를 파일에 내장해 인터넷 없는 교실에서도 동작하는 배포용, dashboard_cdn_dev.html은 같은 라이브러리를 CDN에서 로드하는 개발용입니다. 평소 수정은 개발용에서 하고, 완성되면 배포용 단일 파일을 갱신합니다.
