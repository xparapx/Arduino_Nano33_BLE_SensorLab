01

이 모드는 언제 쓰나

브라우저 대시보드(WebUI)가 PC 기반이라면, phyphox 모드는 스마트폰 기반입니다.

야외 실험·모둠 활동처럼 PC를 쓰기 어려운 상황에서, 학생 각자의 폰에 phyphox 앱(무료, RWTH Aachen 대학 제작)을 설치하고 QR을 찍으면 바로 측정을 시작할 수 있습니다. 그래프·측정값 표시, CSV/Excel 내보내기까지 앱 안에서 해결됩니다.

펌웨어 택일 — phyphox 연동은 WebUI와 다른 BLE 프로토콜을 씁니다. firmware/nano33ble_phyphox_rev2.ino를 업로드하면 WebUI 대시보드는 연결되지 않습니다(반대도 동일). 모드를 바꿀 때마다 해당 펌웨어를 다시 업로드하세요.
02

설치 절차

STEP 1
🔌

펌웨어 업로드

Arduino IDE에서 firmware/nano33ble_phyphox_rev2.ino를 보드에 업로드. 라이브러리 매니저에서 phyphoxBLE 설치 필요.

STEP 2
📲

앱 설치 → QR 스캔

폰에 phyphox 앱 설치 → 앱에서 ＋ → QR 코드 스캔 → 아래 갤러리의 QR을 찍으면 실험이 설치됨.

STEP 3
▶️

연결·측정

설치된 실험을 열고 재생(▶)을 누르면 근처의 Nano 보드에 자동 연결. 그래프 확인 후 메뉴에서 데이터 내보내기(CSV/Excel).

04

자주 묻는 문제

보드가 연결되지 않아요
① 보드에 phyphox 전용 펌웨어(nano33ble_phyphox_rev2.ino)가 올라가 있는지 확인 — WebUI 펌웨어가 올라가 있으면 phyphox에서 보이지 않습니다.
② 폰의 블루투스 켜짐 + phyphox 앱의 근처 기기 권한(Android 12+) 허용 확인.
③ 다른 폰·PC가 이미 보드를 점유 중이면 연결되지 않습니다 — 한 보드에는 한 기기만 연결하세요.
④ 보드 전원을 뽑았다 다시 연결한 뒤 실험 재생(▶)을 다시 누르세요.
연결은 됐는데 값이 안 나와요
① 실험과 펌웨어는 choice 번호로 짝이 맞춰져 있습니다 — 이 페이지의 QR로 설치한 실험만 사용하세요(임의 수정 금지).
② 재생(▶) 상태인지 확인 — 일시정지 상태에서는 그래프가 멈춰 보입니다.
③ 외장 아날로그 실험은 A0~A2에 센서 출력(0~3.3 V)과 GND가 실제로 연결돼 있어야 값이 변합니다.
카톡으로 .phyphox 파일을 보냈는데 안 열려요
Android의 MIME 타입 문제로 .phyphox 파일 직접 전송은 동작하지 않습니다. 파일 대신 QR을 찍게 하거나, phyphox://로 시작하는 링크를 보내세요(위 03 섹션의 배포 안내 참고).
